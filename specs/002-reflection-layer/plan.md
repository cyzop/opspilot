# Implementation Plan: OpsPilot Reflection Layer

**Branch**: `002-reflection-layer` | **Date**: 2026-10-06 | **Spec**: [spec.md](./spec.md)

**Input**: Feature specification from `specs/002-reflection-layer/spec.md`

## Summary

Add an opt-in `withReflection(strategy, options)` decorator around the existing
`ReasoningStrategy`. It reviews the candidate answer against observation events
with Zod-validated structured output from the same OpenRouter model configuration.
Rejected candidates are regenerated by rerunning the wrapped strategy with the
original operator question, prior observations, and critic feedback. The
decorator appends ordered critique events, aggregates base and critic model-call
metrics, and stops on approval or after two regenerations by default. Extend the
arena with `reflect:react` and `reflect:plan-and-execute` selectors and a
reflection-limit option.

## Technical Context

**Language/Version**: TypeScript ESM, Node.js 22 LTS, `strict: true`.

**Primary Dependencies**: Existing `@langchain/core` 1.2.14,
`@langchain/openai` 1.6.2, `@langchain/langgraph` 1.4.18, and Zod 4.6.5;
no new package is required.

**Storage**: No new persistent storage. Each decorated strategy uses the same
base strategy instance and its existing isolated in-memory store across
regenerations.

**Testing**: `node:test` via `tsx`; deterministic fakes for base strategy,
structured critic, callback accounting, and arena factory. Required gates are
`npm test` and `npm run typecheck`; no test calls OpenRouter.

**Target Platform**: Node.js 22 LTS on Windows and other supported Node platforms.

**Project Type**: TypeScript ESM CLI/application with internal agent modules.

**Performance Goals**: Critic work adds one review per candidate; no more than
three reviews or two regenerations with defaults.

**Constraints**: Validate `maxReflection` as a non-negative safe integer,
defaulting to 2. Every critic model invocation counts, including failed calls.
The base strategy's `maxIterations` applies independently to each run; the
decorator sums the metrics of every base run and its own critic calls. Critic
output is `{ approved: boolean, feedback: non-empty string }`. Only operator
input, candidate answer, and `observation` trace events are sent to the critic;
sanitize every field using the shared trace redaction before constructing the
critic prompt. The generic decorator accepts an optional `model` in its options;
arena wiring must pass the same `ChatOpenAI` instance to a reflected base
strategy and its critic, while custom strategies can inject their corresponding
model explicitly. Regeneration adds feedback and available observation evidence
to the original input while preserving the same wrapped strategy instance/store.

**Scale/Scope**: Decorate any existing strategy, expose two reflected arena
selectors, and permit caller-configured reflection retries. Reflection remains
opt-in; existing selector behavior is unchanged.
